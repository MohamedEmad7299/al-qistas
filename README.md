## 📖 Overview | نبذة عن المنصة
**القسطاس (Al-Qistas)** هي منصة إسلامية رقمية شاملة لحساب جميع الفرائض والأحكام الشرعية والمسائل الفلكية بدقة متناهية، وفق أصول ومقررات المذاهب الفقهية الأربعة والقرارات المعتمدة للمجامع الفقهية الكبرى (الأزهر الشريف، مجمع الفقه الإسلامي الدولي، وهيئة كبار العلماء).

تم تصميم المنصة بتصميم إسلامي فاخر مستوحى من المخطوطات والزخارف الهندسية، مع دعم كامل للغتين **العربية والإنجليزية (Ar / En)** مع تبديل الاتجاه (RTL / LTR)، ودعم تصدير **تقارير وشهادات PDF رسمية مطبوعة ومفصلة** لجميع النتائج.

## ✨ Key Features & Calculators | الأقسام والحاسبات

### 1. 📜 حاسبة المواريث والفرائض الشرعية (Inheritance - Al-Fara'id)
- توزيع التركات وفق علم الفرائض الشرعي.
- تحديد أصحاب الفروض والعصبات بدقة.
- معالجة مسائل **العول (Al-'Awl)** و **الرد (Al-Radd)** وحالات الحجب (**حجب الحرمان والنقصان**).
- استخراج أصل المسألة، وحصة كل وارث بالكسور الاعتيادية، والنسبة المئوية، والمبلغ النقدي.
- عرض الأدلة الشرعية والآيات القرآنية من سورة النساء لكل وارث.
- تصدير حصر إرث رسمي PDF معتمد ومزود بختم شرعي.

### 2. 💰 حاسبة الزكاة الشاملة (Comprehensive Zakat Engine)
- **زكاة المال والمدخرات:** حساب السيولة النقدية، والأرصدة البنكية، وعروض التجارة، والديون المرجوة والمخصومة.
- **الذهب والفضة:** حساب دقيق حسب العيار (عيار 24، 21، 18) مع تحديث فوري للنصاب (85 جم ذهب أو 595 جم فضة).
- **التقويم:** دعم الحساب بالتقويم القمري (2.5%) أو الشمسي (2.577%).
- **زكاة الفطر:** حساب عدد أفراد الأسرة ومقادير الصاع نقداً وعيناً.
- **زكاة الزروع والثمار:** التحقق من النصاب (5 أوسق ≈ 653 كجم) وتحديد العشر (10%) أو نصف العشر (5%) أو المشترك (7.5%).
- **زكاة الأنعام:** جداول فقهية كلاسيكية دقيقة للإبل (شاة، بنت مخاض، بنت لبون، حقة، جذعة)، والبقر (تبيع، مسنة)، والغنم.
- **الركاز والمعادن:** حساب الخمس (20%) فور العثور عليه.
- **الأسهم والاستثمارات:** التمييز بين أسهم المضاربة (2.5%) وأسهم الاستثمار طويل الأجل (10% من الأرباح).
- تصدير بيان زكاة شرعي PDF.

### 3. 🕌 مواقيت الصلاة وبوصلة القبلة التفاعلية (Prayers & Qibla)
- معادلات فلكية شمسية دقيقة لحساب أوقات الصلوات الخمس والشروق.
- تحديد الموقع التلقائي (GPS) أو الاختيار من مدن العالم الكبرى.
- دعم الهيئات الفلكية الكبرى (أم القرى، هيئة المساحة المصرية، رابطة العالم الإسلامي، ISNA، كراتشي).
- المذهب في العصر: الشافعي/الجمهور (ظل الشيء مثله) والحنفي (ظل الشيء مثليه).
- **عد تنازلي حي** بالثواني للصلاة القادمة.
- **حاسبة الصيام:** حساب مدة الصيام اليومية، وموعد الإمساك والإفطار.
- **بوصلة القبلة 3D:** زاوية انحراف القبلة نحو الكعبة المشرفة والمسافة بالكيلومترات مع دعم حساس الاتجاه بالهاتف.
- تصدير إمساكية الصلاة الشهرية PDF.

### 4. 🌙 التقويم الهجري وأطوار القمر (Hijri Calendar & Moon Phases)
- محول تقويم ثنائي دقيق (هجري ↔ ميلادي).
- محاكاة طور القمر بالرسوم الفلكية (نسبة الإضاءة، عمر القمر، واسم الطور: محاق، هلال، تربيع، بدر، أحدب).
- قائمة المناسبات والأعياد الإسلامية مع عد تنازلي باليوم والساعة (رمضان، الأعياد، عرفة، عاشوراء، المولد النبوي، إلخ).

### 5. ⚖️ الكفارات والفدية والديات (Expiations & Compensations)
- **كفارة اليمين:** إطعام 10 مساكين (7.5 كجم حبوب أو وجبات أو قيمتها نقداً) أو صيام 3 أيام عند العجز.
- **كفارة الجماع في نهار رمضان:** صيام شهرين متتابعين (60 يوماً) أو إطعام 60 مسكيناً (45 كجم طعام).
- **فدية الصيام:** للعاجز لكبر سن أو مرض مزمن عن كل يوم أفطره.
- **الدية الشرعية:** تقدير الدية الكاملة (100 إبل أو 1000 دينار ذهب = 4.25 كجم ذهب 24) مع التحويل للنقد المعاصر.

### 6. ⏳ حاسبة العِدّة الشرعية ('Iddah Calculator)
- عدة المتوفى عنها زوجها: 4 أشهر و10 أيام (130 يوماً).
- عدة المطلقة ذوات الحيض: 3 قروء / حيضات.
- عدة الآيسة أو التي لم تحض: 3 أشهر قمرية.
- عدة الحامل: بوضع الحمل.
- حساب تاريخ البداية والنهاية الدقيقين بالتقويمين الهجري والميلادي مع بيان الأحكام والإحداد.

### 7. 📈 المعاملات المالية والشراكات الإسلامية (Islamic Finance)
- **المضاربة (Mudarabah):** اقتسام الأرباح وفق النسبة المتفق عليها، وتحمل رب المال للخسارة المالية كاملة.
- **المشاركة (Musharakah):** اقتسام الربح بالشرط، وتوزيع الخسارة حصراً وفق نسبة رأس المال: *«الربح على ما شرطا، والوضيعة على قدر المالين»*.
- **المرابحة (Murabaha):** بيع التكلفة مع الربح المعلوم وجدول الأقساط الشهرية.

### 8. 📄 مركز تصدير تقارير PDF الفاخرة (PDF Export Engine)
- توليد وتنزيل تقارير PDF رسمية عالية الدقة بدون الحاجة لأي خادم خلفي.
- تصميم شهادات إسلامية تقليدية بإطارات مذهبة وختم رقمي معتمد.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend Framework:** React 19 + TypeScript
- **Bundler & Build Tool:** Vite
- **Styling:** Tailwind CSS v4 + Islamic Design System & Arabesque Patterns
- **PDF & Canvas Engine:** `jspdf` + `html2canvas`
- **Icons:** `lucide-react`
- **Hosting:** 100% Free Client-Side on GitHub Pages
